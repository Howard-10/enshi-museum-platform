# 检索重构评测集

阶段 0 的目标是先固定一组可重复的真实问题，避免只凭单次体验判断改造是否有效。

## 评测字段

每一行记录一个问题：

| 字段 | 说明 |
| --- | --- |
| `id` | 稳定的问题编号 |
| `query` | 用户原始问题 |
| `history` | 可选的最近 6 条消息 |
| `expected_query` | 指代消解后的检索问题 |
| `expected_sources` | 期望命中的文档或章节 |
| `media_type` | `image`、`audio`、`video` 或空 |
| `must_not_return` | 不应返回的文档、章节或媒体 |

## 必测场景

- 标题命中：一级标题、二级标题和标题路径检索。
- 章节边界：不同标题下的相同词语不能混为同一证据。
- 代词追问：最近 3 轮内的“它”“这个”“刚才那个”。
- 无历史问题：没有上下文时必须保留原始问题。
- 重复来源：关键词和向量同时命中时只展示一条章节证据。
- 完整证据：用户可见回答和来源内容都不能由服务端追加省略号。
- 媒体文件名：文件名直接命中时按请求类型返回对应对象。
- 媒体缺失：没有高置信度匹配时返回空媒体数组。

## 验收指标

- 标题和章节路径解析正确率不低于 95%。
- 评测问题 Recall@5、首条结果命中率持续记录。
- 相同章节的溯源重复率低于 1%。
- 指代问题改写准确率不低于 90%。
- 媒体误匹配为 0；没有可信匹配时不返回媒体。
- 用户可见回答中不出现由检索层生成的 `…` 或 `...`。

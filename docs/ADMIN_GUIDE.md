# 本机知识库管理端

管理端与游客端分开，地址为 `http://localhost:8080/admin`。

## 第一次开启

1. 打开项目根目录的 `.env`。
2. 增加一行本机令牌，换成你自己保存的长随机字符串：

```dotenv
ADMIN_API_TOKEN=请替换为你自己的本机管理令牌
```

3. 在项目目录重新启动服务：

```powershell
docker compose --profile app up -d --build backend frontend
```

4. 打开管理端地址，在输入框填写同一个令牌。

## 可以管理什么

- 文物目录：修改名称、年代、类别、地点、材质和简介。
- 文档资料：上传 `.docx`、查看分块、标记已审核/待审核/拒绝。
- 图片、音频、视频：上传到 MinIO，按 SHA-256 去重，关联或解除关联文物。
- 操作记录：查看上传、修改、审核、关联和解除关联记录。

## 安全规则

- 游客端没有写入接口入口；所有管理 API 都要求 Bearer 令牌。
- 新上传文档和媒体关联默认为“待审核”，不会自动进入问答。
- 上传文档不会自动调用 embedding，也不会自动扣模型额度。
- 解除媒体关联只移除数据库关系，不删除 MinIO 原文件。
- 当前是本机管理令牌 MVP，不是正式登录系统；正式部署前应替换为学校统一认证或用户角色权限。

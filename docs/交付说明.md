# 恩施博物馆智能导览——代码交付说明

这是从头重构后的前后端分离版本，用于本机演示和后续交接。该交付包不包含旧项目代码、旧 Chroma 向量库、Docker 运行卷、任何真实 API Key 或本机虚拟环境。

## 当前能力

- PostgreSQL 关键词检索、可追溯馆内资料引用、MinIO 图片/音频/视频短时链接。
- Redis + PostgreSQL 会话记录。
- 80 份文档、8,547 个子分块、45 件目录文物、170 个媒体文件的本机导入结果。
- 60 条离线评估全部通过；模型调用与 Tavily 外搜均保持关闭。

## 运行前需要准备

1. Docker Desktop。
2. Python 3.11。
3. Node.js 22。
4. 数据源文件：Word、Excel、音视频/图片需要由项目方另行提供；本包不携带原始资料和 Docker 数据卷。

## 本机启动

```powershell
Copy-Item .env.example .env
docker compose up -d

cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另开一个 PowerShell：

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

访问 `http://127.0.0.1:5173`。

## 关键说明

- `.env.example` 只是模板；不要提交或发送真实 `.env`。
- 未收到学校模型参数前，保持 `EXTERNAL_MODEL_CALLS_ENABLED=false`。
- Tavily 是未来外搜供应商，但当前 `WEB_SEARCH_ENABLED=false` 且月度额度为 0。
- 旧三元组仅供人工审核，未参与问答。审核文件位于 `data/reviews/`。
